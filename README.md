# My-Portfolio

Personal developer portfolio — AI, automation, SaaS, web applications, APIs, and software engineering.

## Stack

- Next.js (App Router) + React + TypeScript
- Tailwind CSS + shadcn/ui
- Motion + Lucide React

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npx tsc --noEmit
npm run build
```
